# Säkerhetspolicy

## Versioner som stöds

Afån består av flera komponenter och program som kan ha egna versionsnummer.

Det finns ingen formell långtidssupport. Säkerhetsproblem hanteras efter bästa förmåga, med fokus på aktuella versioner.

Äldre versioner stöds normalt inte.

## Rapportera säkerhetsproblem

Om du hittar ett säkerhetsproblem i Afån, rapportera det gärna via GitHub.

Beskriv gärna:

* vilken komponent som berörs
* versionsnummer
* vad problemet är
* hur problemet kan återskapas, om möjligt

Rapporterade problem hanteras när möjlighet finns. Det finns ingen garanterad svarstid eller tidsgräns för säkerhetsuppdateringar.

Säkerhetsfixar kan ingå i en vanlig versionsuppdatering och behöver inte ges ut som en separat säkerhetsversion.
